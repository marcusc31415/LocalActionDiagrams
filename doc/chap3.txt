  [1X3.1-1 [33X[0;0YWriting To A String[133X[101X
  
  [33X[1;0Y[29X[2XRSGraphToWritableString[102X( [3Xgraph[103X ) [32X operation[133X
  [33X[1;0Y[29X[2XLocalActionDiagramToWritableString[102X( [3Xlad[103X ) [32X operation[133X
  [6XReturns:[106X  [33X[0;10YA String representation of the object.[133X
  
  [33X[0;0YThese  two  functions  turn an RSGraph or local action diagram into a string
  representation.  The  exact  format  of the representations are described in
  (APPENDIX  REFERENCE). These functions are not designed to store the objects
  in  the  most  space-efficient  format. The formats are designed so that the
  objects can be read into a GAP session with very little overhead and so that
  the objects and known attributes can be recreated in a new GAP session.[133X
  
  [33X[0;0YNote  that these functions do not perform any disk IO operations themselves.
  They  return  a  string in the GAP session and it is up to the user to chose
  how disk IO operations with the string are done.[133X
  
  [33X[0;0YFor an RSGraph the data that is always stored is:[133X
  
  [30X    [33X[0;6Ythe vertex ids,[133X
  
  [30X    [33X[0;6Ythe arc ids,[133X
  
  [30X    [33X[0;6Ythe adjacency list, and[133X
  
  [30X    [33X[0;6Ythe reverse map.[133X
  
  [33X[0;0YIf  the  canonical  labelling  or  automorphism group (REF FUNCTIONS) of the
  RSGraph are known then they are also stored.[133X
  
  [33X[0;0YFor a local action diagram that data that is always stored is:[133X
  
  [30X    [33X[0;6Ythe diagrams RSGraph (and all data known about it),[133X
  
  [30X    [33X[0;6Ythe vertex labels, and[133X
  
  [30X    [33X[0;6Ythe arc labels.[133X
  
  [33X[0;0YThe data stored if it is known is:[133X
  
  [30X    [33X[0;6Ythe diagrams scopos,[133X
  
  [30X    [33X[0;6Ythe corresponding group type,[133X
  
  [30X    [33X[0;6Yif the corresponding group is discrete,[133X
  
  [30X    [33X[0;6Yif the corresponding group is uniscalar,[133X
  
  [30X    [33X[0;6Yif the corresponding group is unimodular, and[133X
  
  [30X    [33X[0;6Ythe name of the corresponding group.[133X
  
  [4X[32X  Example  [32X[104X
    [4X[25Xgap>[125X [27Xgraph := RSGraphByAdjacencyList([[1, 1]], ());;[127X[104X
    [4X[25Xgap>[125X [27XRSGraphToWritableString(graph);[127X[104X
    [4X[28X"1|1,1,1|P"[128X[104X
    [4X[25Xgap>[125X [27Xlad := LocalActionDiagramFromData(graph, [Group((1,2))], [[1,2]]);;[127X[104X
    [4X[25Xgap>[125X [27XLocalActionDiagramGroupType(lad);;[127X[104X
    [4X[25Xgap>[125X [27XLocalActionDiagramToWritableString(lad);[127X[104X
    [4X[28X"1|1,1,1|P/1:P2,1:1,2|1:1,2|LocalActionDiagramGroupType!General|LocalActionDia\[128X[104X
    [4X[28XgramScopos! "[128X[104X
  [4X[32X[104X
  
  
  [1X3.1-2 [33X[0;0YReading From A String[133X[101X
  
  [33X[1;0Y[29X[2XRSGraphFromWritableString[102X( [3Xstring[103X ) [32X operation[133X
  [33X[1;0Y[29X[2XLocalActionDiagramFromWritableString[102X( [3Xstring[103X[, [3Xreturn_graph[103X] ) [32X operation[133X
  [6XReturns:[106X  [33X[0;10YThe object(s) the string represents.[133X
  
  [33X[0;0YThese   function  take  the  output  from  the  [10XRSGraphToWritableString[110X  and
  [10XLocalActionDiagramToWritableString"[110X methods as input and returns the objects
  those strings represents. While it is possible to edit these strings outside
  of  GAP  these  functions  do  not  perform  error  checking and so this can
  potentially  lead to invalid RSGraph or local action diagram objects. If the
  optional    [3Xreturn_graph[103X    parameter    is    set    to   true   then   the
  [10XLocalActionDiagramFromWritableString[110X function will return a list whose first
  entry is the local action diagram object and second intro is the RSGraph for
  this local action diagram.[133X
  
  [33X[0;0YAny  optional attributes known about the objects at the time of writing will
  be  stored  in the objects returned by these functions without needing to be
  recomputed.  Note  that  the (REF canon and aut functions) attributes can be
  stored  in  the  objects  created  by  these  functions  without needing the
  [5XDigraphs[105X  to  be  loaded even though computing these attributes required the
  [5XDigraphs[105X to be loaded.[133X
  
  [4X[32X  Example  [32X[104X
    [4X[25Xgap>[125X [27Xgraph_string := "1|1,1,1|P";;[127X[104X
    [4X[25Xgap>[125X [27Xgraph := RSGraphFromWritableString(graph_string);;[127X[104X
    [4X[25Xgap>[125X [27XPrint(graph);[127X[104X
    [4X[28XVertices = { 1 }[128X[104X
    [4X[28XArcs = {[128X[104X
    [4X[28X	1 = ( origin = 1, terminus = 1, inverse = 1 )[128X[104X
    [4X[28X}[128X[104X
    [4X[28XReverse Map = ()[128X[104X
    [4X[25Xgap>[125X [27Xlad_string := "1|1,1,1|P/1:P2,1:1,2|1:1,2|LocalActionDiagramGroupType!Gene\[127X[104X
    [4X[25X>[125X [27Xral|LocalActionDiagramScopos! ";;[127X[104X
    [4X[25Xgap>[125X [27Xlad := LocalActionDiagramFromWritableString(lad_string);;[127X[104X
    [4X[25Xgap>[125X [27XPrint(lad);[127X[104X
    [4X[28XVertices = { 1 }[128X[104X
    [4X[28XArcs = {[128X[104X
    [4X[28X	1 = ( origin = 1, terminus = 1, inverse = 1 )[128X[104X
    [4X[28X}[128X[104X
    [4X[28XReverse Map = ()[128X[104X
    [4X[28XVertex Labels = {[128X[104X
    [4X[28X	1 = Group( [ (1,2) ] )[128X[104X
    [4X[28X}[128X[104X
    [4X[28XArc Labels = {[128X[104X
    [4X[28X	1 = [ 1, 2 ][128X[104X
    [4X[28X}[128X[104X
    [4X[25Xgap>[125X [27XPrint("LocalActionDiagramScopos" in KnownAttributesOfObject(lad));[127X[104X
    [4X[28Xtrue[128X[104X
    [4X[25Xgap>[125X [27XPrint("LocalActionDiagramIsDiscrete" in KnownAttributesOfObject(lad));[127X[104X
    [4X[28Xfalse[128X[104X

  [1X3.1-3 [33X[0;0YIO Pickling/Unpickling[133X[101X
  
  [33X[1;0Y[29X[2XIO_Pickle[102X( [[3Xfile[103X, ][3Xgraph[103X ) [32X operation[133X
  [33X[1;0Y[29X[2XIO_Pickle[102X( [[3Xfile[103X, ][3Xlad[103X ) [32X operation[133X
  [6XReturns:[106X  [33X[0;10Y[9XIO_OK[109X  or  the  pickle  string  if  the pickling was successful or
            [9XIO_ERROR[109X if there was an error.[133X
  
  [33X[1;0Y[29X[2XIO_Unpickle[102X( [3Xfile[103X ) [32X operation[133X
  [6XReturns:[106X  [33X[0;10YAn  RSGraph  or  Local  Action  Diagram  object  if  successful or
            [9XIO_ERROR[109X if there was an error.[133X
  
  [33X[0;0YThe  IO  package  supports  serialising data through the [10XIO_Pickle[110X function.
  Unlike  the  [10XRSGraphToWritableString[110X  and [10XLocalActionDiagramToWritableString[110X
  functions  these  functions support recreating an arbitrary structure within
  the  memory of a GAP session (assuming that the pickling functions have been
  defined  for  each  object).  In  particular,  it  can  easily recreate data
  structures storing objects.[133X
  
  [33X[0;0YFor  example, if [10Xl[110X is a list of RSGraphs then you can write this list to the
  disk  with  a single call to [10XIO_Pickle[110X. This generality comes at the cost of
  performance.  For this reason, if you have a large collection of RSGraph and
  local  action diagram objects that you need writing to the disk we recommend
  using  the  [10XRSGraphToWritableString[110X  and  [10XLocalActionDiagramToWritableString[110X
  functions.[133X
  
  [33X[0;0YIn  the one argument version for [10XIO_Pickle[110X, the pickle string for the object
  is  returned if the pickling was successful. In the two argument version, an
  IO file opened to write mode is supplied and the pickle string is written to
  this file.[133X
  
  [33X[0;0YThe  [10XIO_Unpickle[110X function accepts either the pickle string as input or an IO
  file  opened  to  read  mode  which stores pickled objects. It recreates the
  objects in memory exactly.[133X
  
  [33X[0;0YAs  a  note for developers, the RSGraph and local action diagram objects are
  pickled with the "magic values" [10XRSGO[110X and [10XLADO[110X respectively.[133X
  
  [4X[32X  Example  [32X[104X
    [4X[25Xgap>[125X [27Xgraph := RSGraphByAdjacencyList([[1, 1]], ());;[127X[104X
    [4X[25Xgap>[125X [27Xlad := LocalActionDiagramFromData(graph, [Group((1,2))], [[1,2]]);;[127X[104X
    [4X[25Xgap>[125X [27Xlist := [graph, lad];[127X[104X
    [4X[28X[ <RSGraph with 1 vertex and 1 arc>, [128X[104X
    [4X[28X  <LocalActionDiagram with 1 vertex and 1 arc> ][128X[104X
    [4X[25Xgap>[125X [27Xfile := IO_File("test.pickle", "w");;[127X[104X
    [4X[25Xgap>[125X [27XIO_Pickle(file, list);[127X[104X
    [4X[28XIO_OK[128X[104X
    [4X[25Xgap>[125X [27XIO_Close(file);;[127X[104X
    [4X[25Xgap>[125X [27Xfile := IO_File("test.pickle", "r");;[127X[104X
    [4X[25Xgap>[125X [27XIO_Unpickle(file);[127X[104X
    [4X[28X[ <RSGraph with 1 vertex and 1 arc>, [128X[104X
    [4X[28X  <LocalActionDiagram with 1 vertex and 1 arc> ][128X[104X
