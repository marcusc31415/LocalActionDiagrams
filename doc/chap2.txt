  
  [1X2 [33X[0;0YLocal Action Diagrams[133X[101X
  
  [33X[0;0YA local action diagram [22X∆ = (Γ, (X_a), (G(v)))[122X consists of:[133X
  
  [30X    [33X[0;6Ya graph [22XΓ[122X (an [10XRSGraph[110X),[133X
  
  [30X    [33X[0;6Yfor  each  arc  [22Xa  ∈  A(Γ)[122Xa [13Xcolour set[113X [22X|X_a|[122X disjoint from every other
        colour set,[133X
  
  [30X    [33X[0;6Yfor  each  vertex [22Xv ∈ V(Γ)[122X a group [22XG(v)[122X labelling the vertex such that
        [22XG(V)[122X acts on [22X⨆_a ∈ o^-1(v)X_a[122X and the orbits of [22XG(V)[122X are precisely the
        colour sets [22X|X_a|[122X for [22Xa ∈ o^-1(v)[122X.[133X
  
  [33X[0;0YLocal  action  diagrams  are  a powerful tool for studying [22X(P)[122X-closed groups
  because  isomorphism  classes  of  local action diagrams are in a one-to-one
  correspondence  with  conjugacy  classes  of [22X(P)[122X-closed groups. Furthermore,
  properties  of the corresponding [22X(P)[122X-closed group can be determined from the
  local  action diagram. In the case when a local action diagram is finite, we
  can   represent   the  diagram  in  [5XGAP[105X  and  determine  properties  of  the
  (potentially infinite) corresponding group.[133X

  [1X2.1-2 LocalActionDiagramFromData[101X
  
  [33X[1;0Y[29X[2XLocalActionDiagramFromData[102X( [3Xgraph[103X, [3Xvertex_labels[103X, [3Xarc_labels[103X ) [32X operation[133X
  [33X[1;0Y[29X[2XLocalActionDiagramFromDataNC[102X( [3Xgraph[103X, [3Xvertex_labels[103X, [3Xarc_labels[103X ) [32X operation[133X
  [6XReturns:[106X  [33X[0;10YA local action diagram object.[133X
  
  [33X[0;0YThis  function  constructs  a  local  action  diagram  by  having all of the
  diagrams  data  given  to  it.  This is done by providing the [10XRSGraph[110X of the
  diagram  and  either lists of vertex and arc labels or records of vertex and
  arc labels.[133X
  
  [33X[0;0YIf  two  lists are provided then the vertex and arc labels are assumed to be
  in   the  same  order  as  [10XRSGraphVertices([3Xgraph[103X[10X)[110X  and  [10XRSGraphArcIDs([3Xgraph[103X[10X)[110X
  respectively.  This means, for example, that element [10Xidx[110X of [3Xvertex_labels[103X is
  the label of the vertex with id [10XRSGraphVertexIDs([3Xgraph[103X[10X)[idx][110X. If two records
  are  provided  then  the names of the record elements are the vertex and arc
  ids respectively and the components are their labels.[133X
  
  [33X[0;0YThe  vertex  labels are permutation groups. The domain each label acts on is
  stored   in  the  mutable  attribute  [10XPermGroupDomain[110X  (see  [2XPermGroupDomain[102X
  ([14X???PermGroupDomain???[114X)).  By  default,  this is equal to the [10XMovedPoints[110X of
  the group but can be changed to allow for the group to have fixed points.[133X
  
  [33X[0;0YThe  arc  labels  are  lists of integers. Each arc must be labelled by by an
  orbit of the vertex label at the vertex that arc originates at. Furthermore,
  every vertex must have an arc originating at it for each orbit of its vertex
  label.  Note that the orbits of a vertex label [10XG[110X are determined by [10XOrbits(G,
  PermGroupDomain(G))[110X.[133X
  
  [33X[0;0YUnlike the formal definition of a local action diagram, we allow for overlap
  between  the  domains  of different vertex labels. For example, a two vertex
  local  action  diagram  could  be  labelled by [22XC_2[122X and [22XS_3[122X and they can have
  domains [22X{1, 2}[122X and [22X{1, 2, 3}[122X respectively.[133X
  
  [33X[0;0YThe NC variant of the function does not check that there is a label for each
  vertex  and  arc  (and  exactly  this  many labels), that the domains of the
  groups match up with the arc labels, or that the orbits of the vertex labels
  match up with the arc labels.[133X

    [4X[25Xgap>[125X [27XPrint(lad);[127X[104X
    [4X[28XVertices = { 1, 2 }[128X[104X
    [4X[28XArcs = {[128X[104X
    [4X[28X        1 = ( origin = 1, terminus = 1, inverse = 1 )[128X[104X
    [4X[28X        2 = ( origin = 1, terminus = 2, inverse = 3 )[128X[104X
    [4X[28X        3 = ( origin = 2, terminus = 1, inverse = 2 )[128X[104X

  [30X    [33X[0;6YFor  each  arc  [22Xa[122X in the graph of [22X∆[122X label the corresponding arc in the
