  
  [1X5 [33X[0;0YEnumeration[133X[101X
  
  [33X[0;0YSince  there  is  a one-to-one correspondence between isomorphism classes of
  local action diagrams and conjugacy classes Of (P)-closed groups enumerating
  local  action  diagrams  is  the  same  as enumerating (P)-closed groups. By
  enumerating  local  action diagrams you can, for example, find the number of
  conjugacy  classes  of  (P)-closed  groups  acting  on a certain tree with a
  specified  number  of  orbits.  You  can  also find how many of these groups
  satisfy other properties, such as unimodularity.[133X
  
  [33X[0;0YWe  have developed algorithms to enumerate local action diagrams acting on a
  regular  tree with a specified number of orbits. For the inputs we could run
  these  algorithms  on  we  have  stored  the  results so they can be quickly
  accessed.  Furthermore,  we  have  implemented  functions  analogous  to the
  [5XTransitive  Groups[105X  package for easily filtering the library of local action
  diagrams.[133X
  
  
  [1X5.1 [33X[0;0YEnumerating RSGraphs and Local Action Diagrams[133X[101X
  
  [1X5.1-1 RSGraphFromLibrary[101X
  
  [33X[1;0Y[29X[2XRSGraphFromLibrary[102X( [3Xdegree[103X, [3Xno_verts[103X[, [3Xidx[103X] ) [32X operation[133X
  [6XReturns:[106X  [33X[0;10YA list of RSGraphs or a specific element from this list.[133X
  
  [33X[0;0YThis  function  returns  a list of RSGraphs such that each vertex has degree
  less  than  or  equal to [3Xdegree[103X and the graph has exactly [3Xno_verts[103X vertices.
  Each graph in the list is unique up to isomorphism. If the optional argument
  [3Xidx[103X  is  provided  then  it  will return the RSGraph in that position of the
  list.  This is analogous to the [10XTransitiveGroup[110X function from the [5XTransitive
  Groups[105X package.[133X
  
  [33X[0;0YThere  are  two ways this function can get the list of RSGraphs. If the data
  for  the  given  degree and number of vertices is stored on the disk then it

  RSGraph enumeration algorithm will be run instead. An information message is
  displayed if the enumeration algorithm is used.[133X

  [1X5.2 [33X[0;0YSearching The Library[133X[101X
  
  
  [1X5.2-1 [33X[0;0YAllRSGraphs/AllLocalActionDiagrams[133X[101X
  
  [33X[1;0Y[29X[2XAllRSGraphs[102X( [[3Xfunction_1[103X, [3Xvalue_1[103X, [3X...[103X] ) [32X operation[133X
  [33X[1;0Y[29X[2XAllLocalActionDiagrams[102X( [[3Xfunction_1[103X, [3Xvalue_1[103X, [3X...[103X] ) [32X operation[133X
  [6XReturns:[106X  [33X[0;10YAll  RSGraphs  or  Local Action Diagrams satisfying the conditions
            given as arguments.[133X
  
  [33X[0;0YThese  functions  return  a  list  of  RSGraphs  or  Local  Action  Diagrams
  satisfying  the  conditions  specified. The functions take an even number of
  inputs which alternate between functions and values. Each function must have
  a  single  argument  as  input  which  is  either an RSGraph or local action
  diagram.  The  output  of  [3Xfunction_i[103X  must  be comparable with the equality
  operation to [3Xvalue_i[103X. The functions are analogous to the [10XAllTransitiveGroups[110X
  function from the [5XTransitive Groups[105X package.[133X
  
  [33X[0;0YThese functions work by first starting with a list of every RSGraph or Local
  Action  Diagram stored on the disk. Each function supplied as an argument is
  applied  to  every  element  of  this  list  and the result of applying this
  function  is  compared with the provided value. If it matches the value then
  the  element  is  kept  in  the  list; otherwise it is discarded. After this
  process  is done for every argument the final list is returned. Note that it
  can be an empty list if there are no elements satisfying all conditions.[133X
  
  [33X[0;0YIf  any of the functions provided are properties or attribute of RSGraphs or
  Local  Action  Diagrams then these functions are prioritised for evaluation.
  This  means  that  any function which is not a property or attribute will be
  evaluated  after each property and attribute is. The reason for this is that
  properties and attributes Are known the by "easy" to calculate or are stored
  in  the  library  data  and  so this can speed up the search by reducing the
  search space for the potentially "harder" functions.[133X
  
  [33X[0;0YThe  first  time one of these functions is called the entire library is read
  into the GAP sessions memory. Information messages are displayed during this
  process as this can take some time. Subsequent calls to this function do not
  need to read the library files.[133X
  
  [33X[0;0YIf  no  arguments  are  provided  then  a complete list of RSGraphs or local
  action diagrams is returned. Furthermore, every degree two RSGraph and local
  action  diagram  can  be  quickly  manually  constructed.  By  default, this
  function  only  includes  those with up to ten vertices. This can be changed
  with the [2XSetLocalActionDiagramDegreeTwoVertexBound[102X ([14X5.2-3[114X) function.[133X
