  
  [1X6 [33X[0;0YExtensions[133X[101X
  
  [33X[0;0YWe  support  converting  between RSGraphs and digraphs from the [5XDigraphs[105X and
  graphs from the [5XGRAPE[105X. Converting from an RSGraph returns both the (di)graph
  and all data needed to convert back to the original RSGraph.[133X
  
  
  [1X6.1 [33X[0;0YDigraphs Conversion[133X[101X
  
  [1X6.1-1 RSGraphToDigraph[101X
  
  [33X[1;0Y[29X[2XRSGraphToDigraph[102X( [3Xrsgraph[103X ) [32X attribute[133X
  [6XReturns:[106X  [33X[0;10YA record containing the digraph and all data needed to reconstruct
            the RSGraph.[133X
  
  [33X[0;0YGiven  an  RSGraph  this function converts is to a digraph from the [5XDigraphs[105X
  package.  A  record  is  returned  containing  both the digraph and all data
  needed to reconstruct the original RSGraph. The record returned contains the
  elements:[133X
  
  [30X    [33X[0;6Y[10Xdigraph[110X:  a digraph representing the graph structure (an object in the
        category [10XIsDigraph[110X.)[133X
  
  [30X    [33X[0;6Y[10Xreverse_map[110X: the reverse map of the original RSGraph.[133X
  
  [30X    [33X[0;6Y[10Xvertex_id_map[110X:  a  bijective  map  from  the  vertices of the original
        RSGraph  to  the  vertices  of the digraph which determines the vertex
        correspondence between the RSGraph and digraph.[133X
  
  [30X    [33X[0;6Y[10Xarc_id_map[110X:  a  bijective map from the arcs of the original RSGraph to
        the  edges  of  the  digraph  which  determines the arc correspondence
        between the RSGraph and digraph.[133X
  
  [33X[0;0YAs  an  example, if [10X2[110X is a vertex in the RSGraph then [10X2^vertex_id_map[110X is the
  corresponding  vertex in the digraph. All digraphs returned by this function
  have  vertices labelled from [22X1[122X to [22Xn[122X where [22Xn[122X is the number of vertices in the
  RSGraph.  Arc  [10Xi[110X  in  the  digraph  is  the  arc  in  the  [10Xi[110Xth  position  of
  [10XDigraphEdges(digraph)[110X --- i.e. [10XDigraphEdges(digraph)[i][110X.[133X
  
  [4X[32X  Example  [32X[104X
    [4X[25Xgap>[125X [27Xgraph := RSGraphByAdjacencyList([[2, 3], [3, 2]], (1,2), [2, 3]);;[127X[104X
    [4X[25Xgap>[125X [27Xdigraph_rec := RSGraphToDigraph(graph);;[127X[104X
    [4X[25Xgap>[125X [27Xdigraph_rec.digraph;[127X[104X
    [4X[28X<immutable digraph with 2 vertices, 2 edges>[128X[104X
    [4X[25Xgap>[125X [27X2^digraph_rec.vertex_id_map;[127X[104X
    [4X[28X1[128X[104X

  [1X6.1-3 RSGraphFromDigraph[101X
  
  [33X[1;0Y[29X[2XRSGraphFromDigraph[102X( [3Xdigraph[103X, [3Xreverse_map[103X ) [32X operation[133X
  [6XReturns:[106X  [33X[0;10YAn RSGraph.[133X
  
  [33X[0;0YGiven  a  [3Xdigraph[103X and a [3Xreverse_map[103X defined on the edges of the digraph this
  function  returns an RSGraph with the same structure as the digraph and with
  the reverse map provided. This function works by using the adjacency listing
  of  the  digraph given by [10XDigraphEdges([3Xdigraph[103X[10X)[110X. This means that the reverse
  map  must  be compatible with the order of the edges given by this adjacency
  listing.[133X
  
  [33X[0;0YAll  normal  checks  for an RSGraph construction are applied when using this
  function.  In  particular, this means that the digraph must be connected and
  must have a reverse arc for every arc in the digraph.[133X
