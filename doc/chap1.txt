  
  [1X1 [33X[0;0YRSGraphs[133X[101X
  
  [33X[0;0YAn  RSGraph  is a graph [22XΓ = (V, A, o, r)[122X that consists of a vertex set [22XV[122X, an
  arc  set  [22XA[122X,  a map [22Xo : A -> V[122X which assigns each vertex to an [13Xorigin[113X, and a
  bijection  [22Xr : A -> A[122X which assigns each arc to a [13Xreverse[113X arc. There is also
  a  map  [22Xt  :=  o  ∘  r[122X which assigns each arc to a [13Xterminus[113X vertex. Note the
  RSGraphs are allowed to contain loops and parallel arcs.[133X
  
  [33X[0;0YWe  created  the  RSGraph  object  for this package due to our use of graphs
  having  a  specialised definition. For example, every arc in an RSGraph must
  have  a  reverse  arc  associated  with it while a [13XDigraph[113X from the [5XDigraphs[105X
  allows  for  arcs that do not have an associated reverse arc. Creating a new
  object  category  for  RSGraphs  allows  for both better error checking when
  using  RSGraphs and to avoid conflicting definitions, such as the definition
  of a cycle for a Digraph and an RSGraph. We provide functionality to convert
  between  an RSGraph and a [13XGraph[113X from the [5XGRAPE[105X package or a [13XDigraph[113X from the
  [5XDigraphs[105X package.[133X
  
  [33X[0;0YThe  name  "RSGraph"  arises  from  Reid and Smith, the authors of the local
  action  diagram  paper.  This  name was chosen to avoid conflicting with the
  [5XGRAPE[105X package.[133X
  
  
  [1X1.1 [33X[0;0YCreating RSGraphs[133X[101X
  
  [1X1.1-1 IsRSGraph[101X
  
  [33X[1;0Y[29X[2XIsRSGraph[102X( [3Xobj[103X ) [32X Category[133X
  [6XReturns:[106X  [33X[0;10Y[9Xtrue[109X if [3Xgraph[103X is of the category [10XIsRSGraph[110X and [9Xfalse[109X otherwise.[133X
  
  [33X[0;0YEvery  RSGraph  object belongs to the category [10XIsRSGraph[110X. Furthermore, every
  RSGraph is an immutable attribute storing object.[133X
  
  [1X1.1-2 RSGraphByAdjacencyList[101X
  
  [33X[1;0Y[29X[2XRSGraphByAdjacencyList[102X( [3Xadjacency_list[103X, [3Xreverse_map[103X[, [3Xvertex_ids[103X] ) [32X operation[133X
  [33X[1;0Y[29X[2XRSGraphByAdjacencyListNC[102X( [3Xadjacency_list[103X, [3Xreverse_map[103X[, [3Xvertex_ids[103X] ) [32X operation[133X
  [6XReturns:[106X  [33X[0;10YAn RSGraph.[133X
  
  [33X[0;0YThis  function  creates  an  RSGraph  described  by  an  adjacency list. The
  argument  [3Xadjacnecy_list[103X  is  a  list of the from [10X[[origin, terminus], ...][110X.
  Each  arc  in  the graph is given an id which corresponds to its position in
  the list [3Xadjacency_list[103X.[133X
  
  [33X[0;0YThe  reverse  map  must  be  a  permutation  that  is an involution --- i.e.
  [10Xreverse_map*reverse_map  = ()[110X. Furthermore, if element [3Xidx[103X of [3Xadjacency_list[103X
  is [10X[u, v][110X then [3Xadjacency_list[idx^reverse_map][103X must equal [10X[v, u][110X.[133X
  
  [33X[0;0YBy  default,  the  vertices are labelled with ids [22X{1, 2, dots, n}[122X where [22Xn[122X is
  the  maximal element of [10XFlat(adjacency_list)[110X. If the optional third argument
  [3Xvertex_ids[103X is given then these are taken to be the vertex ids. This argument
  must be a dense list of integers.[133X
  
  [33X[0;0YFinally, the underlying graph must be connected.[133X
  
  [33X[0;0YThe  NC  variant of the function does not check that the graph is connected,
  the reverse map is valid, and that each arc has an associated reverse arc.[133X
  
  [4X[32X  Example  [32X[104X
    [4X[25Xgap>[125X [27Xadj_list := [[1, 2], [2, 1], [2, 2], [2, 2], [1, 1]];;[127X[104X
    [4X[25Xgap>[125X [27Xrev_map := (1,2)(3,4);;[127X[104X
    [4X[25Xgap>[125X [27Xgraph := RSGraphByAdjacencyList(adj_list, rev_map);[127X[104X
    [4X[28X<RSGraph with 2 vertices and 5 arcs>[128X[104X
    [4X[28X[128X[104X
    [4X[25Xgap>[125X [27Xadj_list2 := [[2, 2]];;[127X[104X
    [4X[25Xgap>[125X [27Xrev_map2 := ();;[127X[104X
    [4X[25Xgap>[125X [27Xvertex_ids := [2];;[127X[104X
    [4X[25Xgap>[125X [27Xgraph := RSGraphByAdjacencyList(adj_list, rev_map, vertex_ids);[127X[104X
    [4X[28X<RSGraph with 1 vertex and 1 arc>[128X[104X
  [4X[32X[104X
  
  [1X1.1-3 RSGraphByAdjacencyMatrix[101X
  
  [33X[1;0Y[29X[2XRSGraphByAdjacencyMatrix[102X( [3Xadjacency_matrix[103X, [3Xreverse_map[103X[, [3Xvertex_ids[103X] ) [32X operation[133X
  [33X[1;0Y[29X[2XRSGraphByAdjacencyMatrixNC[102X( [3Xadjacency_matrix[103X, [3Xreverse_map[103X[, [3Xvertex_ids[103X] ) [32X operation[133X
  [6XReturns:[106X  [33X[0;10YAn RSGraph.[133X
  
  [33X[0;0YThis  function  creates  an  RSGraph  described  by an adjacency matrix. The
  argument [3Xadjacnecy_matrix[103X is an [22Xn × n[122X matrix represented by a list of lists.
  This  means  that  there are [22Xm[122X arcs between vertices [22Xu[122X and [22Xv[122X of the graph if
  [10Xadjacency_matrix[u][v] = m[110X.[133X
  
  [33X[0;0YThe matrix is read in row-major order to determine the arc ids of the graph.
  This  is important for determining the reverse map of the graph. The reverse
  map   must   be   a   permutation   that   is   an   involution   ---   i.e.
  [10Xreverse_map*reverse_map = ()[110X.[133X
  
  [33X[0;0YBy  default,  the  vertices  are  labelled  with ids [22X{1, 2, dots, n}[122X where [22Xn[122X
  [10XSize(adjacency_matrix)[110X  ---  i.e.  the  number  of rows (and columns) of the
  matrix.  If  the  optional third argument [3Xvertex_ids[103X is given then these are
  taken  to  be the vertex ids. This argument must be a dense list of integers
  and  element  [10Xidx[110X  of  the  list  will be the label of the vertex in row and
  column [10Xidx[110X of [3Xadjacency_matrix[103X.[133X
  
  [33X[0;0YFinally, the underlying graph must be connected.[133X
  
  [33X[0;0YNote  that  the  first  argument  must  be a list of lists with each sublist
  containing  integers. In particular, it can not be an object in the category
  [9XIsMatrixObj[109X constructed by the function [10XMatrix[110X.[133X
  
  [33X[0;0YThe  NC  variant of the function does not check that the graph is connected,
  the reverse map is valid, and that each arc has an associated reverse arc.[133X
  
  [4X[32X  Example  [32X[104X
    [4X[25Xgap>[125X [27Xadj_mat := [[1, 2], [2, 0]];;[127X[104X
    [4X[25Xgap>[125X [27Xrev_map := (2, 4)(3,5);;[127X[104X
    [4X[25Xgap>[125X [27Xvertex_ids := [2,3];;[127X[104X
    [4X[25Xgap>[125X [27Xgraph := RSGraphByAdjacencyMatrix(adj_list, rev_map, vertex_ids);[127X[104X
    [4X[28X<RSGraph with 2 vertices and 5 arcs>[128X[104X
    [4X[28X[128X[104X
    [4X[25Xgap>[125X [27XPrint(graph);[127X[104X
    [4X[28XVertices = { 2, 3 }[128X[104X
    [4X[28XArcs = {[128X[104X
    [4X[28X        1 = ( origin = 2, terminus = 2, inverse = 1 )[128X[104X
    [4X[28X        2 = ( origin = 2, terminus = 3, inverse = 4 )[128X[104X
    [4X[28X        3 = ( origin = 2, terminus = 3, inverse = 5 )[128X[104X
    [4X[28X        4 = ( origin = 3, terminus = 2, inverse = 2 )[128X[104X
    [4X[28X        5 = ( origin = 3, terminus = 2, inverse = 3 )[128X[104X
    [4X[28X}[128X[104X
    [4X[28XReverse Map = (2,4)(3,5)[128X[104X
  [4X[32X[104X

  [1X1.3-2 RSGraphSubgraph[101X
  
  [33X[1;0Y[29X[2XRSGraphSubgraph[102X( [3Xgraph[103X, [3Xarc_list[103X ) [32X operation[133X
  [33X[1;0Y[29X[2XRSGraphSubgraphNC[102X( [3Xgraph[103X, [3Xarc_list[103X ) [32X operation[133X
  [6XReturns:[106X  [33X[0;10YAn arc induced subgraph of [3Xgraph[103X.[133X
  
  [33X[0;0YGiven  a  graph  and  list  of arcs in this graph, this function returns the
  subgraph  consisting exactly of those arcs and the vertices connecting them.
  The  vertex  ids,  arc  ids,  and  reverse  map are preserved. Note that the
  reverse  map  is not changed and so may act on a larger set of integers than
  is strictly necessary.[133X
  
  [33X[0;0YIf  an  arc is in [3Xarc_list[103X then its reverse must also be in it. Furthermore,
  the resulting subgraph must be connected.[133X
  
  [33X[0;0YThe  NC  variant of this function does not check for connectivity or for the
  inclusion of arc reversals.[133X
  
  [4X[32X  Example  [32X[104X
    [4X[25Xgap>[125X [27Xadj_list := [[1, 2], [2, 1], [1, 2], [2, 1], [2, 2]];;[127X[104X
    [4X[25Xgap>[125X [27Xrev_map := (1,2)(3,4);;[127X[104X
    [4X[25Xgap>[125X [27Xgraph := RSGraphByAdjacencyList(adj_list, rev_map);;[127X[104X
    [4X[25Xgap>[125X [27XPrint(graph);[127X[104X
    [4X[28XVertices = { 1, 2 }[128X[104X
    [4X[28XArcs = {[128X[104X
